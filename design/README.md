# Kitescreen icon: concept C

The two rounded display outlines and flowing link represent a Windows screen extending to an Android tablet over USB. `Kitescreen-Icon-C.png` is the approved square master artwork. The Windows ICO contains sizes 16–256 px. Android uses legacy launcher PNGs plus an adaptive foreground on a midnight navy background (`#071A32`). Keep the foreground within the Android mask's center safe area when regenerating the assets.
